# 📚 Talleres de lógica de programación en JavaScript

Más de 90 ejercicios resueltos en JavaScript para construir una base sólida de lógica de programación, organizados por tema.

![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

| Carpeta | Tema | Ejemplos |
|---|---|---|
| [`cicloos/`](cicloos/) | Ciclos `for` y `while` | Factorial, tablas de multiplicar, números impares, ecuación cuadrática, lanzamiento de dados |
| [`funciones/`](funciones/) | Funciones | Contar y quitar vocales, validar contraseñas, promedios, facturación |
| [`arreglos javascripts/`](<arreglos javascripts/>) | Arreglos | Recorrer, filtrar y transformar listas |
| [`arreglos miscelanea/`](<arreglos miscelanea/>) | Arreglos (mezcla) | 19 ejercicios combinando arreglos con ciclos y condicionales |
| [`problemas logicos/`](<problemas logicos/>) | Resolución de problemas | 16 problemas con su vista en HTML |
| [`ejercicios german/`](<ejercicios german/>) | Condicionales | Números primos, divisibilidad, edad, IVA, ángulos |

## Cómo ejecutarlos

La mayoría de los ejercicios piden datos con `prompt` y muestran el resultado con `alert`, así que se ejecutan en el navegador: abre el archivo `.html` de la carpeta (por ejemplo `cicloos/vista.html`) y cambia el script que carga para probar cada ejercicio.
